"Solarized" is a warm, low-contrast theme built on Ethan Schoonover's sixteen-colour palette — a cream canvas with muted blue-grey text, the palette's blue as the primary accent, and its dark teal (`base02`) carried into the global navigation.

Solarized is a precision-engineered colour scheme by Ethan Schoonover, not a component framework.
The original palette is available at [https://ethanschoonover.com/solarized/](https://ethanschoonover.com/solarized/).
