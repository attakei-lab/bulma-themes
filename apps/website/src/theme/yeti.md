"Yeti" is a flat, friendly theme: a bright sky-blue accent over a clean white-and-grey canvas. Its signature is the absence of ornament — square corners everywhere, thin light-weight Open Sans type, and a joined pagination strip where only the current page carries the fill.

This is a theme from the Bootswatch collection for Bootstrap.
The original demo is available at [https://bootswatch.com/yeti/](https://bootswatch.com/yeti/).
