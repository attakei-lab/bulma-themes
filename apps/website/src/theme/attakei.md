attakei's color theme is a petrol-blue palette — the color attakei reaches for by default, here and on any other Bulma-based site.

Primary sits at a hue bridging navy and teal. Link is pulled toward an independent deep teal rather than matching primary's shade, and info / success / warning / danger share primary's saturation so the whole palette reads as one family, spaced apart in hue so none of them gets mistaken for a tint of primary.

Everything outside of color — radius, shadow, spacing, button styling — is left at Bulma's own defaults. This theme is a statement about color, not shape.
