"Sandstone" is a warm, flat theme: earthy sand tones — tan borders over cream surfaces — with a muted navy primary and a distinctive yellow-green link colour. Its type is set in uppercase, medium-weight labels across buttons, tabs, pagination and breadcrumbs.

This is a theme from the Bootswatch collection for Bootstrap.
The original demo is available at [https://bootswatch.com/sandstone/](https://bootswatch.com/sandstone/).
